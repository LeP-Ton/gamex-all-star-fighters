## 目标与范围
用户最终要求三个 Boss 的完整游戏。本阶段围绕其优先级，先实现独立 60 Hz 战斗系统、原创首场资源、李铁四种机制、中文街机界面、存档与验证。首场尚未达到动画/手感质量门槛，因此没有批量制作许家印、释永信，也未以首场胜利伪装完整通关。

## 当前有效结论
- 首场可在 PC 浏览器运行，克隆后 `npm ci` 安装、`npm run dev` 启动。
- 31 项自动化测试通过；类型检查及生产构建通过；最终依赖审计为 0 项漏洞。
- 主角与 Boss 资源均为内置 imagegen 生成的原创初稿，不宣称正式美术达标。
- 正式挑战只允许查看判定框；调参和强制触发技能限自由练习，训练不参与最佳成绩。
- 任务中的人物技能是虚构玩法；李铁图鉴单列已确认司法事实与来源。
- 无伤按剩余生命等于满血判断，防御削血不能因受击计数为0被误认为无伤。
